Getting started with Grim Void
==============================
Grim Void is Grim OS built on Void Linux: musl, runit, xbps, and Grim's own tools.

  grimhelp              this help, quick settings and the app centre (menus)
  grimctl               the system command (grimctl help lists everything)
  grim-wifi             find your Wi-Fi hardware and join a network
  grim-session          start a desktop from the console
  grimfetch             system info (grimfetch --live for live CPU/RAM)
  grim-spotify          Spotify in the terminal

Your whole system is described in one file:  /etc/grim/system.conf
Edit it and run "sudo grimctl apply". See: grimhelp system
