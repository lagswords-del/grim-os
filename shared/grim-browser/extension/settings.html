Privacy

Grim Browser never sends telemetry or usage data anywhere, and that can't be switched on.

Block ads and trackers
Private windows through Tor
Every private window's traffic goes through the Tor network. Normal windows stay direct and fast.
Hide your fingerprint
Sites see a common, generic browser: a standard window size, UTC time, English, a US keyboard layout, a common operating system and fewer hardware details. Some sites look slightly different.
Hide your IP from WebRTC
Video calls still work; sites can't read your local or real IP through WebRTC.

Sites where blocking is off

    Burn

    One click to start over: cookies, history, cache, downloads list, form data and every site's stored data are deleted, every tab closes, and Tor gets a new identity. Saved passwords and bookmarks stay. Shortcut: Ctrl+Shift+Delete.

    Extensions

    Grim Browser runs normal Firefox extensions. Get them from addons.mozilla.org; manage them in the ☰ menu → Add-ons and themes (or press Ctrl+Shift+A).

    Good ones that respect your privacy:

    • uBlock Origin: also hides ad boxes inside pages (Grim Shield blocks by domain).
    • Bitwarden: open-source password manager.
    • Dark Reader: dark mode for every site.
    • Multi-Account Containers: keep logins separate.
    • LibRedirect: opens YouTube, Reddit and others through private front-ends.

    About

    Grim Browser is Firefox with Grim OS's settings and the Grim Shield extension. It sends no telemetry, studies, crash reports, sponsored content or Safe Browsing lookups. Firefox still checks Mozilla's list of harmful add-ons, so a known-bad extension can be switched off.

    The icon is Iceraven's (MPL-2.0), recoloured for Grim OS. Private windows use Tor but are not Tor Browser: for the strongest anonymity, use Tor Browser.
